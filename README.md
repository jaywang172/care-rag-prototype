# 居服員 RAG 問答系統｜專題試做版

使用者提問後，系統只從 `data/docs/` 的文件檢索，由 Gemini 依文件回答並附來源。文件沒有依據時直接說找不到。

## 啟動

需要 Node.js 20 以上，不需安裝其他套件。

1. 建立 `.env`，內容為 `GEMINI_API_KEY=你的金鑰`
2. 建立索引（第一次或文件更新後）：`npm run ingest`
3. 啟動：`npm start`，開啟 http://127.0.0.1:5173/
4. 流程：點此進入 → 員工登入（任意帳密＋滑塊）→ 照護問答

跑測試題庫：`npm run eval`，結果寫入 `tests/results.json`。

## 運作方式

| 步驟 | 做法 | 位置 |
| --- | --- | --- |
| 分流 | 用藥決定、當下緊急狀況直接回固定訊息，不產生答案 | `lib/rag.mjs` |
| 檢索 | `gemini-embedding-001` 向量＋餘弦相似度，取前 8 段 | `lib/rag.mjs` |
| 回答 | Gemini 以結構化輸出回答，每個重點必須附原文引用 | `lib/rag.mjs` |
| 驗證 | 引用必須逐字存在於該段落，否則該重點捨棄；全部捨棄即視為找不到依據 | `lib/rag.mjs` |

## 更新文件

在 `data/sources.json` 登記文件名稱、版本與網址，文字放到 `data/docs/<id>.txt`，以 `@@ 第3頁` 或 `@@ 章節名` 標示位置，再執行 `npm run ingest`。

## 目前不能處理的情況

- 不做緊急照護判斷，也不提供用藥建議。
- 帳號為示範用，輸入任意帳密即可登入。
- 只回答單一問題，不會延續上一題的脈絡。
- 掃描成圖片的 PDF 內容、文件中的圖片不在知識庫內。
- 語音輸入依賴瀏覽器支援，建議使用 Chrome。
- 來源為公開衛教資料，不等於機構 SOP，正式使用前需由專業人員審核。
