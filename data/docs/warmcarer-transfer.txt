@@ 前言
活動活動，要活就要動。面對慢性病纏身，行動不便而無法自行活動、轉移位的長輩們，該如何協助他們輕鬆轉移位呢? 日常生活中，翻身、坐起、下床、站立、行走，這些日常活動，看似不經意卻不可或缺。在轉位期間，照顧者如何最省力又安全的執行 ? 亦或，長輩及照顧者兩方要如何搭配方能達到最佳成效呢 ?
轉移位中，長輩在許可狀態下做到下列三點，可協助出力 : 雙腳著地及踏地、膝蓋後收彎曲角度小於90度、上半身微微向前傾斜。
照顧者姿勢則須注意 : 腰挺直、膝蓋微彎曲、雙腳打開，並運用輔具協助。兩者相互配合，可避免造成腰痠背痛，並免除拉傷跌倒等等狀況。
@@ 移位七大情境教學
下方列出移位照顧中常見幾種情境 :
@@ 床上翻身協助
讓長輩平躺於床上，雙手抱胸，或以健側手拉住患側手置於胸前，臉朝向欲翻身側，使雙腳彎曲成90度，照顧者一手扶長輩膝蓋、一手扶肩膀，將長輩翻向側面。
@@ 床上坐起協助
長輩翻身後，將長輩小腿垂放於床緣外側，照顧者將一手伸進長輩脖子下方環繞肩膀，另一手撐住膝蓋，以臀部做為支點，利用槓桿原理扶起長輩呈坐姿。如長輩狀況許可，可以雙手支撐床面維持身體穩定。
@@ 床上 -> 輪椅
輪椅擺放與床呈40-45度，輪椅踏板收起及剎車。將呈現坐姿的長輩臀部前移至床緣，雙腳踩地、膝蓋內縮或呈90度彎曲，照顧者一腳站於長輩雙膝間、拉住長輩褲頭，使長輩雙手環抱照顧者肩膀， 往前帶動再往上提，轉向輪椅側坐下。如長輩狀況許可，可請長輩伸手扶持輪椅遠端扶手，使長輩將中心向前，方便起身。
@@ 輪椅 -> 馬桶
將長輩的輪椅移動與馬桶呈45度角，輪椅踏板收起及剎車。照顧者一腳腳尖朝向馬桶，另一腳朝向輪椅呈弓箭步，使長輩雙手環抱照顧者肩膀，以拉褲頭方式將長輩向前向上扶起，脫下褲子，轉向至馬桶上坐下。如體力較差無法站立的長輩，可先在輪椅上先脫掉褲子。
@@ 輪椅 -> 車內
上車時，將長輩的輪椅移動與車身呈45度角，輪椅踏板收起及剎車。照顧者一腳腳尖朝向車門，另一腳朝向輪椅呈弓箭步，此時重心放在朝向輪椅的腳，使長輩雙手環抱照顧者肩膀，以拉褲頭方式將長輩向前向上扶起，轉向車門，並轉移重心到朝向車門那腳，將長輩轉身移位到車內，再將雙腳移入車中，協助坐好後繫上安全帶。如長輩可自行由輪椅起身走入車內，則以健側上車為佳，可抓握車門鉤、椅背、頸枕或車窗保持平衡。(小提醒 : 讓屁股先上車，先移動身體再移動腳，並小心避免撞到頭部)
@@ 車內 -> 輪椅
下車時，將輪椅至於與車身45度角，輪椅踏板收起及剎車，將長輩雙腳移動到車外地面，使長輩面向外側，照顧者可一左一右將長輩臀部移動往車門方向，照顧者一腳腳尖朝向輪椅，另一腳朝向車門呈弓箭步，此時重心放在朝向車門的前腳，使長輩雙手環抱照顧者肩膀，以拉褲頭方式將長輩扶起轉向輪椅，，如長輩狀況許可可扶持輪椅遠端扶手，協助長輩在輪椅上坐好。(小提醒 : 先移動雙腳到車下再移動身體)
@@ 坐姿 -> 站立
將長輩身體向前移動，調整坐於座椅1/2處，雙腳與肩同寬，身體向前傾斜使下巴超過膝蓋，使重心往前移動，再向斜前方站起，在膝蓋即將打直前再挺直上半身軀幹，保持身體穩定。照顧者可拉住長輩褲頭，提供向前向上的力氣協助。
@@ 善用輔具-移位好幫手
市面上有許多轉移位輔助設備，這些輔具的使用，是必須要學習與練習，才能夠熟能生巧，下面介紹幾種常見轉移位輔具 :
移位滑墊或移位滑布 : 以低阻力布料或是凝膠填裝塑膠材料製作，讓長輩在照顧者協助下以滑動的方式進行轉換位置，提供水平施力的協助。
轉位滑板 : 通常以低阻力材質製作，主要作為坐姿移動時使用，連結床與輪椅或便盆椅間的空隙。
移位腰帶 : 通常以織帶製成，類似於寬版腰帶，並有數個橫向及直向拉提把，提供行走練習、床與輪椅間轉位、預防跌倒時使用。
旋轉盤 : 分為坐式及站式，可將長輩轉動至各不同角度，方便轉動下床或是上下車，提供扭轉的協助。
移位機 : 通常以尼龍布料製成懸吊帶，可在不同空間之間進行移位。
@@ 你必須知道！政府輔具資源
依據長期照顧服務申請及給付辦法規定，符合長照服務請領資格者，經照顧管理專員評估有輔具需求，逕轉介至直轄市、縣(市)主管機關自行或委託輔具資源中心、復健相關醫事機構，完成輔具評估報告書，長輩就可以至地方政府特約社區藥局及醫療器材行單位購置或租賃輔具、及居家無障礙環境改善。
可租賃服務項目計有15項，民眾可依照自身需求進行租借。附上長照輔具購買及修繕特約服務單位名單提供參考。
